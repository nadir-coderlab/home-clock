# ساعة البيت

شاشة توقف للتلفزيون فيها: الساعة، التاريخ الهجري، الصلاة الجاية (أم القرى)، رمضان، إجازات المدارس، الطقس، وصورة Bing اليومية. وتخفت بالليل.

- `web/` الصفحة نفسها، وتنشر على GitHub Pages، والصور تتحدّث كل يوم.
- `tizen/` غلاف تطبيق سامسونج (Tizen) يفتح الصفحة.
- الإعداد من الرابط: `?city=madinah|makkah|jeddah|taif|riyadh|dammam`
